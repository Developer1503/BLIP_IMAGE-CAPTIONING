# 🖼️ BLIP Image Captioning  
Generate high-quality image captions using the BLIP (Bootstrapping Language-Image Pre-training) model.

This project provides a simple and efficient interface to upload an image and get an automatically generated caption using a pretrained BLIP model from Hugging Face.

---

## 🚀 Features
- ✔️ Uses **Salesforce BLIP pre-trained model**  
- ✔️ Fast CPU/GPU inference  
- ✔️ Simple Python API / Web-app interface  
- ✔️ Clean & minimal code structure  
- ✔️ Works with JPG, PNG, JPEG formats  

---

## 🧠 About BLIP (Bootstrapping Language-Image Pretraining)
BLIP is a powerful vision-language model capable of:
- Image captioning  
- Image–text retrieval  
- Visual Question Answering (VQA)

This project uses the pretrained BLIP model specifically for **image caption generation**.
